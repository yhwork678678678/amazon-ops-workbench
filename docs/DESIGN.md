# 设计文档

文档版本：`v0.1.0`

最后更新：`2026-08-05`

## 1. 设计目标

本项目是亚马逊运营人员每天打开使用的个人工作台。界面要像内部工具，而不是营销官网。

核心设计目标：

- 快速进入高频工具。
- 快速记录今天的运营动作。
- 快速测算单品利润和广告后的真实利润。
- 临时存放当天会用到的文件，但不上传到公网。
- 让后续功能扩展保持清晰边界。

## 2. 使用场景

典型一天的使用顺序：

1. 打开工作台。
2. 从概览区确认今天巡检顺序。
3. 打开 Seller Central、Amazon Ads、Keepa 等外部工具。
4. 用利润测算器临时估算 SKU 是否值得推。
5. 把广告报表、竞品截图或 Listing 草稿放入临时文件区。
6. 把调价、广告、库存、Listing 改动写入备忘录。

## 3. 信息架构

页面采用单页工作台结构：

- 左侧导航：概览、常用工具、利润测算、文件区、备忘录。
- 顶部操作区：一句当前工作说明，加两个快捷动作。
- 概览区：每日运营巡检流程和本地数据计数。
- 工具区：外部运营工具入口。
- 测算区：利润输入与结果输出。
- 检查区：上架前检查清单。
- 文件区：分为浏览器本地临时文件区，以及通过 Worker 写入私密 GitHub 仓库的上传文件区。
- 备忘区：新增、展示、删除运营备忘。

## 4. 视觉方向

界面类型：运营型 SaaS dashboard。

方向选择：工业化、克制、偏内部系统。

颜色：

- 背景：温暖纸色 `#f4f1ea`。
- 主表面：`#fffdf8`。
- 文字：深墨色 `#171611`。
- 次级文字：`#6e6a5f`。
- 主强调：青绿色 `#0d766f`。
- 辅助强调：琥珀色 `#c77d1b`。
- 风险色：`#a93f35`。

排版：

- 主字体：`Aptos`, `Segoe UI`, `Microsoft YaHei UI`, sans-serif。
- 数据和标签字体：`Cascadia Mono`, `JetBrains Mono`, Consolas, monospace。
- 不使用夸张大标题，不做营销式 hero。

组件形态：

- 卡片圆角控制在 8px。
- 按钮使用图标 + 简短文字。
- 表单控件保持固定边界，避免内容变化导致布局跳动。
- 重点状态用颜色和数字表达，不堆装饰。

## 5. 响应式设计

桌面端：

- `280px` 左侧导航固定。
- 右侧为可滚动工作区。
- 概览和数据卡片使用网格。
- 利润测算和检查清单左右分栏。
- 文件区和备忘区左右分栏。

窄屏端：

- 左侧导航变为顶部普通区块。
- 导航按钮两列排列。
- 所有主模块改成单列。
- 表单和结果条改成单列。
- 文件行在小屏下允许按钮换行，避免横向溢出。

## 6. 交互设计

常用工具：

- 点击工具卡片后用新窗口打开外部链接。
- 每个工具入口显示用途，不只显示名称。

利润测算：

- 输入变化即重新计算。
- 计算参数保存在 `localStorage`。
- 利润为负时显示风险色。

临时文件区：

- 点击上传区或顶部按钮选择文件。
- 文件保存到 IndexedDB。
- 文件列表支持下载和删除。
- 页面明确提示文件不会上传到 GitHub。

上传文件区：

- 需要输入上传密钥后才能选择文件上传。
- 前端调用 Cloudflare Worker，Worker 使用 secret 中的 GitHub token 写入私密仓库。
- 上传成功后展示文件名、大小、上传时间、仓库路径和 GitHub 查看入口。
- GitHub token 不进入前端代码、localStorage 或仓库文件。

备忘录：

- 标题、标签、正文三项输入。
- 标题为空时使用“未命名备忘”。
- 标签为空时使用“运营”。
- 新备忘插入到最前面。
- 支持删除单条备忘。

日常巡检流程：

- 默认展示库存、广告、Listing 和复盘四个流程。
- 支持新增、编辑、删除单条流程。
- 支持恢复默认流程。
- 流程数据保存在当前浏览器的 `localStorage`。

提醒功能：

- 巡检流程支持准时、提前 5/10/30 分钟提醒。
- 备忘录支持设置具体日期和时间。
- 页面每 30 秒检查一次提醒，并在顶部显示未来 24 小时内的事项。
- 用户允许浏览器通知后，额外发送系统通知。
- 页面关闭后暂不保证提醒；离线提醒需要后端或第三方推送服务。

## 7. 技术设计

当前是纯前端静态应用。

主要状态：

- `notes`：React state + localStorage 持久化。
- `files`：React state + IndexedDB 持久化。
- `calculator`：React state + localStorage 持久化。

主要函数：

- `readStoredNotes()`：读取备忘。
- `readStoredCalculator()`：读取测算参数。
- `openFileDatabase()`：打开 IndexedDB。
- `getStoredFiles()`：读取文件列表。
- `putStoredFile()`：保存文件。
- `removeStoredFile()`：删除文件。
- `formatBytes()`：格式化文件大小。
- `openExternal()`：打开外部工具链接。

## 8. 约束

- 不能把真实业务文件提交到仓库。
- 当前不实现用户登录。
- 当前不实现远程文件同步。
- 当前不把 Amazon API key 或 token 写入前端。
- 每次改动后运行 `npm run build`。

## 9. 未来设计扩展

如果接 Cloudflare R2：

- 文件区变为“本地暂存 + 云端同步”两段。
- 增加上传进度、失败重试、分享链接、过期时间。
- 增加文件来源标识：本地、云端、已失效。

如果接 Amazon SP-API：

- 增加 OAuth 授权流程。
- 前端不直接保存 secret。
- API 请求放到后端或 serverless function。
- 增加数据更新时间和授权状态。

如果接广告 CSV 解析：

- 优先本地解析，不上传原始文件。
- 增加字段映射提示。
- 输出异常关键词、异常广告组、预算消耗和 ACOS 风险。
