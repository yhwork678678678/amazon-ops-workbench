# 设计文档

文档版本：`v0.1.14`

最后更新：`2026-08-26`

## 1. 设计目标

本项目是亚马逊运营人员每天打开使用的个人工作台。界面要像内部工具，而不是营销官网。

核心设计目标：

- 快速进入高频工具。
- 快速记录今天的运营动作。
- 快速测算单品利润和广告后的真实利润。
- 通过私密仓库存取需要跨设备使用的运营文件。
- 让后续功能扩展保持清晰边界。

## 2. 使用场景

典型一天的使用顺序：

1. 打开工作台。
2. 从概览区确认今天巡检顺序。
3. 用利润测算器临时估算 SKU 是否值得推。
4. 把需要跨设备使用的运营文件上传到私密文件区。
5. 把调价、广告、库存、Listing 改动写入备忘录。

## 3. 信息架构

页面采用单页工作台结构：

- 左侧导航：备忘录、概览、利润测算、文件区，与右侧主内容顺序一致。
- 顶部操作区：按需显示的通知入口。
- 概览区：每日运营巡检流程。
- 测算区：利润输入与结果输出。
- 文件区：通过 Worker 写入私密 GitHub 仓库，支持文件上传、预览和下载。
- 备忘区：位于主内容前部，新增、编辑、展示、删除运营备忘。
- 导航会根据当前滚动位置高亮对应模块。

## 4. 视觉方向

界面类型：运营型 SaaS dashboard。

方向选择：工业化、克制、偏内部系统。

颜色：

- 背景：温暖纸色 `#f4f1ea`。
- 主表面：`#fffdf8`。
- 文字：深墨色 `#171611`。
- 次级文字：`#6e6a5f`。
- 主强调：青绿色 `#0d766f`。
- 辅助强调：琥珀色 `#c77d1b`。
- 风险色：`#a93f35`。
- 侧栏使用纯色表面和克制的当前项高亮，不使用装饰性纹理。
- 顶部操作区保持轻量右对齐，不单独占用大块卡片空间。

排版：

- 主字体：`Aptos`, `Segoe UI`, `Microsoft YaHei UI`, sans-serif。
- 数据和标签字体：`Cascadia Mono`, `JetBrains Mono`, Consolas, monospace。
- 不使用夸张大标题，不做营销式 hero。

组件形态：

- 卡片圆角控制在 8px。
- 按钮使用图标 + 简短文字。
- 表单控件保持固定边界，避免内容变化导致布局跳动。
- 重点状态用颜色和数字表达，不堆装饰。

## 5. 响应式设计

桌面端：

- `280px` 左侧导航固定。
- 右侧为可滚动工作区。
- 概览和数据卡片使用网格。
- 利润测算使用单列宽布局。
- 备忘区位于主内容前部，文件区单独占一行。

窄屏端：

- 左侧导航变为顶部普通区块。
- 导航按钮两列排列。
- 所有主模块改成单列。
- 表单和结果条改成单列。
- 文件行在小屏下允许按钮换行，避免横向溢出。

## 6. 交互设计

利润测算：

- 输入变化即重新计算。
- 计算参数保存在 `localStorage`。
- 利润为负时显示风险色。

上传文件区：

- 需要输入上传密钥后才能选择文件上传。
- 前端调用 Cloudflare Worker，Worker 使用 secret 中的 GitHub token 写入私密仓库。
- 上传成功后展示文件名、大小、上传时间、仓库路径和 GitHub 查看入口。
- 支持从私密仓库刷新文件列表。
- 支持通过 Worker 代理预览和下载文件，不直接暴露 GitHub 私密仓库内容地址。
- GitHub token 不进入前端代码、localStorage 或仓库文件。

备忘录：

- 标题、标签、正文三项输入。
- 标题为空时使用“未命名备忘”。
- 标签为空时使用“运营”。
- 新备忘插入到最前面。
- 点击时间线中的编辑按钮后回填标题、标签、正文和提醒时间。
- 编辑状态下可保存修改或取消编辑；保存时保留原记录的创建时间。
- 支持删除单条备忘。
- 备忘记录按日期和时间排列成时间线，日期和时间显示在左侧，正文显示在右侧。
- 备忘录表单和展示逻辑封装在 `NotesPanel` 组件中。

日常巡检流程：

- 默认展示库存、广告、Listing 和复盘四个流程。
- 支持新增、编辑、删除单条流程。
- 支持恢复默认流程。
- 流程数据保存在当前浏览器的 `localStorage`。

提醒功能：

- 巡检流程支持准时、提前 5/10/30 分钟提醒。
- 备忘录支持设置具体日期和时间。
- 页面每 30 秒检查一次提醒，并在顶部显示未来 24 小时内的事项。
- 用户允许浏览器通知后，额外发送系统通知。
- 页面关闭后暂不保证提醒；离线提醒需要后端或第三方推送服务。

## 7. 技术设计

当前是纯前端静态应用。

构建更新检测：

- 页面启动后以 `cache: no-store` 请求最新 `index.html`。
- 比较当前入口 JS 和最新入口 JS 的构建哈希；不同则自动刷新当前页面。
- 只刷新页面资源，不清理 `localStorage`、上传记录或上传密钥。

主要状态：

- `notes`：React state + localStorage 持久化。
- `calculator`：React state + localStorage 持久化。

主要函数：

- `readStoredNotes()`：读取备忘。
- `readStoredCalculator()`：读取测算参数。
- `formatBytes()`：格式化文件大小。
- `openExternal()`：打开外部工具链接。

## 8. 约束

- 不能把真实业务文件提交到仓库。
- 当前不实现用户登录。
- 当前不实现远程文件同步。
- 当前不把 Amazon API key 或 token 写入前端。
- 每次改动后运行 `npm run build`。

## 9. 未来设计扩展

如果接 Cloudflare R2：

- 文件区变为“本地暂存 + 云端同步”两段。
- 增加上传进度、失败重试、分享链接、过期时间。
- 增加文件来源标识：本地、云端、已失效。

如果接 Amazon SP-API：

- 增加 OAuth 授权流程。
- 前端不直接保存 secret。
- API 请求放到后端或 serverless function。
- 增加数据更新时间和授权状态。

如果接广告 CSV 解析：

- 优先本地解析，不上传原始文件。
- 增加字段映射提示。
- 输出异常关键词、异常广告组、预算消耗和 ACOS 风险。
